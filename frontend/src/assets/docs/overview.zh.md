# 概览与已验证状态

本页是 Neo 智能账户工作台的中文概览。

- 该系统以一份协议版本 4 的核心实现智能账户能力，同时提供 custom（C#）内核与 native 内核
- 账户身份为 `hash160(0xAA524704 || custody || salt)`，用户无需为每个账户单独部署新合约
- 授权与策略以 validator / hook 模块实例安装，通过 24 小时成熟的配置意图变更
- 支持 Neo 原生签名与 EVM EIP-712 操作签名
- 恢复由核心自带：托管自救助加可选恢复权限，7–90 天时限，到期后任何人都可提交
- 前端支持匿名草稿协作与客户端 / 中继双路径提交，中继从不代替账户授权

更详细的工作原理，请优先阅读 **工作原理与使用指南**、**核心架构**、**工作流生命周期** 与 **数据流与存储**。
