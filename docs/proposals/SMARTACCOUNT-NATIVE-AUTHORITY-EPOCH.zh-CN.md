# 原生 ABI 2 模块权威纪元

原生恢复终止先前的权威代次。SmartAccount 原生合约推进 `AuthorityEpoch`，分离验证器与钩子根及其依赖，且不依赖对旧模块的回调。身份、资产地址、nonce 通道与冻结状态保持不变。已恢复的所有者必须在重新安装模块之前配置全新的模块策略。重新安装旧模块不得恢复其先前的密钥、许可名单、限额、支出状态或快照。

六个受支持原生配置档中的所有账户自有存储都使用该键：

```
0xA2 || policyPrefix || accountIdLE20 || authorityEpochLE64 || policySuffix
```

这些配置档是 NeoNativeVerifier、SessionKeyVerifier、MultiSigVerifier、WhitelistHook、DailyLimitHook 与 TokenRestrictedHook。它们的账户 getter、配置、校验、后置执行、清理、签名方域读取与前缀枚举都使用同一键构造器。每次键构造都从固定原生合约的 safe `getAuthorityEpoch(accountId)` 方法读取当前纪元；它只接受无符号 64 位 Integer。缺失账户、缺失 ABI 支持与格式错误的纪元都会失败关闭。不存在对旧键或缓存纪元的回退。全局模块管理与已授权 core 存储不是账户自有的，并保留其既有键。

`AuthorityEpoch` 仅在恢复时变化。`ConfigurationNonce` 参与 ABI 2 签名域，但不得为模块状态提供命名空间：配置一个子级必须保留其已配置同级子级的凭据。两个计数器用途不同。账户记录在确切 14 字段 ABI 2 记录的索引 13 处暴露该纪元。配置档元数据为 `native-v2`。`0xA2` 命名空间标记防止旧的仅账户代币记录匹配新的前缀扫描，即使其前八个代币字节恰好等于某个纪元。这要求全新的 ABI 2 原生模块；旧的仅账户键被故意设为不可达，包括在纪元零处。不支持就地 ABI 1 迁移。公开的已部署 V3 配置档保留其既有存储键与签名域。

普通的延迟模块清理只删除当前代次。恢复可能在存储中留下旧代次字节，但没有任何受支持的 getter 或执行路径可以读取它们。这是权威撤销，而不是物理数据擦除。

MultiSig 还为每个子级提供对原始参数与原始目标结果的独立深度物化。快照在首个子级回调之前捕获，绝不复用先前的已修改子级值。只有确切的 Boolean true 计入阈值；不受支持的 Interop/迭代器值会使序列化失败并中止，而不是共享可变引用。原生校验与后置执行授权以及签名方域保持分离。

必需的实 VM 回归从已配置的活动策略开始，在不执行旧模块清理的情况下恢复，重新安装相同模块，并证明其旧凭据与策略不存在。新策略必须在新代次中生效，而其他账户保持不变。包含全部六个配置档，并校验纪元零与非零纪元的原始键字节。组合测试必须在一个子级中修改嵌套参数/结果，并验证后续子级与调用方保留其原始值。编译、仅宿主键检查与形式化抽象是补充证据；它们不能替代这些执行，也不确立公共网络部署准备就绪。

## 模块 VM 回归

常规 `scripts/verify_repo.sh --contracts-only` 门禁会自动运行该模块回归，包括配合 `--skip-contract-build`；隔离探针会构建自己的生产模块。`NEOOS_NATIVE_EPOCH_RECEIPT` 选择持久化报告路径；默认情况下门禁打印临时回执路径。编译、还原或 VM 失败会以非零退出码停止门禁。

要在仓库根目录单独运行它：

```sh
source scripts/dotnet_env.sh
python3 scripts/native_epoch_probe.py --compiler "$NCCS_BIN" --output /tmp/native-epoch-vm.json
```

这会把实际的六个原生模块编译进临时树，并在已发布的 NeoVM 中执行它们。固定原生地址上的仅测试 SmartAccount ABI fixture 提供宽松的回调授权与显式纪元设置器。它确立模块存储隔离与组合对象所有权，而不是原生恢复授权、原生准入、回调 gas 充足性或链持久化。报告记录复制的生产/测试源码、已提交的还原锁与编译工件。每个模块与 fixture 都从这些锁以锁定模式还原；显式原生依赖门禁会清点两个探针项目。任何编译器输出都不会被修补。该回归不替代单独的发布构建与工件打包门禁。

该矩阵包括全新重新配置、未受影响的同级账户、不删除先前代次的清理、确切的纪元类型/范围/LE64，以及一个在没有 `0xA2` 时会与纪元零前缀冲突的旧无标记代币键。组合对照演练两个批准阶段、确切的 Boolean 投票、嵌套参数/结果修改、调用方原始结果的保留，以及对 Interop 迭代器结果的拒绝。诊断叶子是显式手写的测试字节码；组合与六个策略 NEF 是真实编译器输出。私有原生恢复/重新安装矩阵仍是必需的。
